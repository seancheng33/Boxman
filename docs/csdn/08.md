# Godot 入门（08）：撞墙判定，数组地图与边界

> 上一篇小人总算会走了，可它有个毛病——会穿墙。
> 往左按十下，它就从画面左边溜出去，连个招呼都不打。
> 今天给它一张真正的地图，再教它一件事：有些地方，你去不了。

## 一、地图不用画，敲几行字就行

做推箱子，最省事的地图不是画出来的，是**敲出来的**。

```gdscript
const MAP := [
	"################",
	"#..............#",
	"#..##########..#",
	"#..#........#..#",
	"#..#........#..#",
	"#..#........#..#",
	"#..#........#..#",
	"#..#........#..#",
	"#..#........#..#",
	"#..##########..#",
	"#..............#",
	"################",
]
```

一个字符串数组，每一行就是地图的一行。`#` 是墙，`.` 是地板。改地图就是改这几行字，比在编辑器里一块块摆砖头快得多，改完直接跑，也不用等它导入。

画出来是这样：

![起点 cell(1,1)，四周一圈全是墙](../img/08/08_run.png)

凑近了看，你就能对上号：

![放大看：# 是深色墙块，. 是更暗的地板](../img/08/08_map.png)

深色实心方块就是 `#`，更暗的是 `.`。数组里写了什么，画面上就是什么，一个字符对一格。

至于画线、画砖块纹理那些，留到后面做视觉打磨再说。现在先把「哪能走」这件事定死。

## 二、数组下标就是格子坐标

这句话值得单独说，因为我在这卡过。

数组是**一行一行**存的，所以取一个格子要写成 `MAP[y][x]`——**y 在前，x 在后**。你习惯的 `(x, y)` 在这里是反的。

我第一次就写成了 `MAP[x][y]`（x 在前），人物沿着对角线乱窜，还以为是输入映射配错了。查了半天，才发现行列写反了，得按 `MAP[y][x]` 取。这种错不会报错，它只会让你的人物走得很诡异。

## 三、走之前，先问一句

核心就一个函数：

```gdscript
func is_wall(c: Vector2i) -> bool:
	# 越界一律当墙，边界判定就这么顺手带上了
	if c.y < 0 or c.y >= MAP.size():
		return true
	var row: String = MAP[c.y]
	if c.x < 0 or c.x >= row.length():
		return true
	return row.substr(c.x, 1) == WALL
```

前半段是**边界**，后半段是**墙**。两件事塞进一个函数里，调用的时候根本不用分心。

这里有个我很喜欢的偷懒写法：**走出数组范围，就当它是墙**。

想想看，边界这东西，很多人会单独写一堆 `if x < 0` 、`if x >= 宽度` 的判断，散落在四个方向里，写四个漏一个。可边界说到底就是「地图外面那一圈不能走的地方」——跟墙是一回事。既然是一回事，就让它返回 true 好了，判定的地方一行都不用多写。

## 四、先算后判，别先走再退

这是本篇最容易写错的地方。

很多人（包括当年的我）会这么写：

```gdscript
# 别学这个：先走一步，撞了再退回来
cell += dir
if is_wall(cell):
	cell -= dir
```

看着也没毛病对吧？能跑。

但它在给你埋雷。等你后面往这个格子里加箱子、加目标点，或者移动之后要播个动画、记一步撤销，「先走再退」就会变成「先改了三个地方，再挨个回滚三个地方」。漏一个，游戏状态就跟你的人物对不上，这种 bug 最难查——因为它只在特定顺序的操作下才冒出来。

正确的做法是**先把想去的地方算出来，问完再决定动不动**：

```gdscript
var target := cell + dir
if is_wall(target):
	return          # 这一步作废，cell 不动，人也不动

cell = target
```

`target` 是个临时变量，判定不过关，直接 `return`，什么都没发生过。干净，而且将来加什么都不用动这段逻辑。

## 五、跑起来，撞一下试试

我把人物放在 cell(1,1)，就是左上角那条走廊。头顶上那格 `(1,0)` 是 `#`，是墙。

## 六、几个小提醒

字符串取单个字符用 `substr(c.x, 1)`，别直接拿下标去和 `#` 比，类型对不上会静默失败——Godot 不报错，它就一直返回 false，你就一直能穿墙。

常量数组 `MAP[r]` 拿出来是 `Variant`，赋值给变量时要写清楚类型：`var row: String = MAP[r]`。不写的话 Godot 会甩你一个 Parse Error，说它推断不出类型。我第一次就被这个拦在门外。

## 写在最后

今天三句话。地图就是字符串数组，`#` 是墙 `.` 是地板。越界当墙，边界和判定合一。先算 target 再判定，不通过就 return，千万别先走再退。
