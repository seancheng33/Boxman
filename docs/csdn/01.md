# Godot 入门实战（01）：下载安装与中文界面设置，零基础 5 分钟开箱

> 本系列目标：从一个空文件夹开始，做出一个能选关、能存档、能导出成 Windows 和网页版的完整推箱子游戏。不需要任何编程基础，每一篇只讲一个知识点。

先说说我为什么劝你入坑 Godot。

三年前我想做个小游戏的时候，在 Unity 和 Godot 之间纠结了一晚上。最后让我下决心的不是技术参数，而是一件特别小的事：Unity 装一次要半个多小时、十几个 GB，而 Godot 一个压缩包，解压就能用，整个引擎还不到 100MB。对，就这么离谱。

这一篇我们就干三件事：**装上它、切成中文、建好第一个项目**。别急，全程 5 分钟。

## 一、Godot 到底是个啥

一句话：**免费、开源、轻量的游戏引擎**，2D 和 3D 都能做。

展开说三点，都是对新手实打实友好的：

- **完全免费，没有分成陷阱。** 不像某些引擎，收入超过门槛就要抽成。Godot 用 MIT 协议开源，你拿它做的游戏赚钱，一分钱都不用分给它。
- **体积小到可以装 U 盘。** 官网下载一个 zip 包，解压出只有一个 exe，双击就能跑。没有安装器、没有注册账号、没有启动器登录。
- **自带脚本语言 GDScript。** 语法长得像 Python，几行就能让一个东西动起来，本系列后面所有代码都会带着你一行行敲。

版本选择上，本系列用的撰写时最稳的 **Godot 4.2.2**。Godot 4 和 3.x 的 API 差异不小，网上老教程很多基于 3.x，跟着敲会报错——看到"3.x 教程"请自觉绕道，或者做好翻译心理准备。

## 二、下载与安装：解压就算装完了

打开官网 `godotengine.org`，点顶部的 **Download**，选 **Godot Engine - Standard version**（标准版）的 Windows 版本，下载下来是一个几十 MB 的 zip。

安装流程如下，我建议你真的照着做一遍：

1. 把 zip 解压到一个**纯英文路径**下，比如 `D:\Godot\`（路径带中文偶尔会出幺蛾子，别给自己埋雷）；
2. 解压出来一个 `Godot_v4.2.2-stable_win64.exe`，可以右键发送到桌面快捷方式；
3. 双击它——没有第三步，这就是全部安装过程。

第一次启动会看到这个界面，叫**项目管理器**（Project Manager），相当于游戏的"存档大厅"，你所有的项目都会列在这里：

![项目管理器首次启动](../img/01/01_pm_first.png)

这时候它还会凑上来问一句"目前没有任何项目，要不要看看官方示例项目？"——点**取消**就行，示例项目都是从在线资产库拉的，咱自己造：

![零项目提示弹窗](../img/01/01_pm_empty_prompt.png)

## 三、切成中文界面

如果你的 Windows 是简体中文系统，Godot 第一次启动就会**自动跟随系统语言**，右上角直接显示 `[zh_CN] Chinese, China`，你什么都不用做。

如果你看到的界面是英文的，改起来也就三秒：点项目管理器**右上角标题栏里的语言选择器**（就是显示 `English` 的那个下拉），语言列表会整个展开：

![语言选择下拉](../img/01/01_pm_language.png)

这个列表按字母排序，一直往下滚到最底部，找到 **[zh_CN] Chinese, China** 点选，界面立刻变中文。这个设置会记住，下次启动不用再改。

顺带说一句，Godot 的中文翻译覆盖度相当高，整个编辑器几乎看不到英文残留，这对零基础读者是实打实的减负。

## 四、新建你的第一个项目

回到项目管理器，点左上角**「+ 新建」**，弹出新建项目对话框，需要确认四个地方：

![新建项目对话框](../img/01/01_new_project_dialog.png)

- **项目名称**：填 `tutorial`，跟我的教程工程保持一致，后面每篇的代码可以直接对照；
- **项目路径**：选一个空文件夹（对话框可以帮你创建）。还是那个原则——**纯英文路径**；
- **渲染器**：三个选项里选**兼容**。为什么不是看起来最炫的 Forward+？「兼容」用 OpenGL 3 后端，老显卡能跑、2D 渲染最快，而且以后导出网页版必须走这条路。咱做 2D 推箱子，它就是最优解；
- **版本控制元数据**：选「无」。以后你把项目放进 Git 仓库时再启用也不迟，现在选了反而会生成一堆让你困惑的文件。

填完点**「创建并编辑」**，进度条一闪，编辑器就开了：

![编辑器首次打开](../img/01/01_editor_first.png)

看到这个界面，恭喜你，开发环境已经 100% 就绪。中间那片 3D 网格视图先不用管，左上角有 **2D / 3D / Script** 三个标签可以切换工作区——下一篇我们重点逛这个编辑器，把每个面板的用途摸清楚。
