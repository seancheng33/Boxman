## 二、发现并修正的内容错误

### 1. 第 07 篇：技术表述错误（CSDN / 公众号两版都有）

**原文**：「只在数据上 `cell += dir`，人物会瞬移，硬跳看着像掉帧。」

**问题**：这句话是错的。`cell` 只是我们自己记的格子号，精灵真正的位置是它自己的 `position` 属性，两者不是一回事。只改 `cell` 不写回 `position`，结果是**黄框在跑、精灵原地纹丝不动**——不是瞬移，是压根没动。零基础读者照着写完会一脸问号。

**实证**：

```
初始      cell=(3, 2)  player_pos=(96, 64)
只改cell   cell=(3, 3)  player_pos=(96, 64)  -> 精灵原地不动？true
写回pos    cell=(3, 3)  player_pos=(96, 96)
```

**修正后**：先讲清 `cell` 与 `position` 的区别 → 直接赋值能走但是瞬移 → 用 tween 摊到 0.12 秒才顺眼。

### 2. 第 08 篇：表述自相矛盾（CSDN 版）

**原文**：「我第一次写反了…才发现是 `MAP[x][y]` 写成了 `MAP[y][x]`。」—— 前后方向打架。

**修正**：「我第一次就写成了 `MAP[x][y]`（x 在前）…才发现行列写反了，得按 `MAP[y][x]` 取。」
