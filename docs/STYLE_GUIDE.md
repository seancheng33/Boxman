# 「山岚的运维笔记」博客教程写作风格基准

> 版本：v1.0（2026-10-20 定稿，基于《Godot 入门实战》第 01 篇迭代）
> 适用范围：所有博客 / 教程类文章（CSDN、公众号等平台），以后写作一律以本基准为准。

## 一、总基调

- 幽默轻松、不过分正式；第一人称实战记录，像跟朋友聊天，不像写报告。
- 每篇只讲一个知识点，讲透，不贪多。
- 必须能过平台 AIGC 检测（见第三节手法清单）。

## 二、方言配比：普通话骨架 + 约 30% 粤味

主体用普通话，粤味只落在两类位置：

- **语气助词点缀**：啦、咯、喇、即刻、讲到明为止、好对照、住在这里
- **标志性关键词**：搞掂、唔使、冇嘢、嘅（少量）、吹水、白嫖、落（下载/放下）、嘢、犀利

浓度自检：非粤语区读者必须能无痛读完；粤味词隔几段出现一次，起味但不设卡。

### 禁用词表（北方官话腔，出现即改）

| 禁用 | 替代 |
|---|---|
| 整（作动词，"整一个"） | 做、搞（搞掂保留，粤语词） |
| 咱 / 咱们 | 我们 |
| 嘞 | 啦 / 了 |
| 唬人 | 吓人 |
| 贼X（贼好、贼快） | 特别好、飞快 |
| 唠 / 咋 / 得劲 / 老铁 | 聊 / 怎么 / 很棒 / 朋友 |
| 儿化音（这块儿、一会儿） | 这部分、等一下 |

## 三、去 AIGC 检测手法清单

1. **禁排比堆叠**：不用"三个理由""四个优势"式对称列表腔，改叙述推进；确实要列点时，点与点长短、句式必须不齐。
2. **长短句交错**：连续两句等长的句子出现即拆或并；允许碎片句（"没了。""就这么短。"）。
3. **闲笔与自嘲**：每篇至少两处跑题一句再拉回（下载 Unity 劝退、U 盘揣引擎之类的真实感细节）。
4. **口语插入语**：别急、说人话、白嫖、劝退、讲道理、行、对，就这么离谱。
5. **禁模板化过渡**：不用"首先/其次/最后""综上所述""值得一提的是"；小标题直接说事。
6. **具体压倒抽象**：能写"30 多 GB 的安装器"就不写"体积庞大"；数字、路径、报错原文都是好素材。

## 四、结构规范

### CSDN 版
- 标题：关键词前置（Godot 等）+ 编号（01/02…），≤30 字
- 文件头 HTML 注释：标题 / 摘要 / 标签（3~5 个）/ 截图清单（发布时按序上传）
- 开头 3 行钩子 → 关键词小标题分节 → 高亮代码块 → GitHub 仓库说明 → 文末「点赞收藏 + 关注山岚的运维笔记」

### 公众号版
- 标题口语化（给 2 个备选），不堆关键词
- 去表格、代码精简或改截图、无外链（GitHub 以文字提示）
- 文末「点赞 / 在看 / 关注」，**不诱导分享**（合规红线）

### 截图
- 全部真实运行截图（编辑器 / 运行画面），禁 AI 生图
- 路径 `docs/img/<篇号>/<篇号>_<名称>.png`，每篇 4~8 张
- Markdown 引用相对路径 `../img/...`，**两个平台都直接嵌真实图片**，不写文字占位符（2026-10-22 起）
- 公众号版想看排版效果，打开 `docs/preview/index.html`（图片就地显示，按公众号样式排版）

## 五、系列工程约定

- 教程工程：仓库 `tutorial/` 目录（Godot 4.2.2，GL Compatibility）
- 每篇完成打 tag：v0.1、v0.2……读者可下载对应进度完整工程
- 粤味浓度如需调整，另出 `_cantonese`（全粤味）/ `_cantonese_light`（本基准默认）对照文件
