我用个 60MB 嘅压缩包，装咗人生第一个游戏引擎

大家好，我系「山岚的运维笔记」。

新系列今日开张喇。先同你立个 flag：接下来一段日子，我要带住完全零基础嘅你，由一个空文件夹开始，整一个正正经经嘅推箱子游戏出嚟——可以选关、可以存档，最后仲可以打包做 Windows 程序同网页游戏咁滞。

唔使识写代码，唔使识美术，甚至连「游戏引擎」四个字点解都唔使知。一篇净系讲一件事，讲到明为止，你跟住做就得。

今日第一篇，先搞掂最易劝退嗰关：装环境。

**点解系 Godot**

做游戏嘅引擎一大把，我向新手首推 Godot，理由讲出来有啲土：佢真系免费，而且细到离谱。

免费到咩程度？有啲引擎嘅套路系入门白送、你只游戏揾到钱佢就抽佣。Godot 系开源社区维护嘅，你用佢做嘅游戏卖到断货，佢一分都唔收。

细到咩程度？官网落个 zip，解压出嚟一个小 exe，冇喇。我出街成日将佢放入 USB 手指，想同人 demo 就插落去，几有当年带绿色版软件出门嗰阵嘅潇洒。

写代码用 GDScript，同 Python 生得似两兄弟，之后系列入面所有代码我都会一行一行带住你敲，你净系照抄就得。

版本提一提：我哋用 Godot 4.2.2。网上好多旧教程系 3.x 嘅，接口对唔上，跟住敲实报错，见到记得行开，咪同自己过唔去。

**安装，我尽量写得长啲**

点解话尽量写得长？因为真系冇嘢好写。

官网 godotengine.org，点 Download，落 Windows 标准版，得到一个 zip。解压去一个纯英文路径，例如 D:\Godot，双击入面个 exe。

冇喇。成个安装过程就系咁多。

第一次打开系呢个画面，叫项目管理器，你当佢系「项目大厅」啦，以后你只游戏全部住喺呢度：

（图1：项目管理器首次启动）

佢啱啱开仲会热心咁问你使唔使睇下官方示例项目，点取消：

（图2：零项目提示弹窗）

我哋系嚟自己动手嘅，唔去逛人哋屋企个后花园。

**切中文，三秒搞掂**

冷知识：Godot 会自动跟系统语言行。你部机系简体中文 Windows，一开就系中文，呢段可以直接跳过。

见到英文界面嘅朋友，喺项目管理器右上角有个语言下拉，一开就成串语言列表哗一声跌出嚟：

（图3：语言选择下拉）

碌到最底，[zh_CN] Chinese, China 喺度等你，点佢，即刻变中文。设定会自己记住，下次唔使再整。

**建第一个项目**

返主界面，点左上角「+ 新建」，一笪选项睇落几吓人，其实得四处要望一眼：

（图4：新建项目对话框）

名称填 tutorial，同我个教程一致，之后代码好对照；路径拣个英文嘅空文件夹；渲染器拣最下面嗰个「兼容」——2D 行得最快，旧显卡都带得起，之后导出网页版仲要靠佢，拣贵唔代表拣啱；版本控制拣「无」，依家开咗净系会提前生成一堆你睇唔明嘅文件。

点「创建并编辑」，编辑器就开出来：

（图5：编辑器首次打开）

恭喜晒，开发环境呢part，你已经系 ready 状态。中间嗰片先唔使理，下一篇我带行匀成个编辑器俾你睇。

**最后**

今日做掂嘅嘢数一数：解压个包，确认中文，白嫖个空项目。一行代码都冇写，但「装环境」呢关拦落嘅人，仲多过后便啲代码拦落嘅加埋，你今日已经跳过个坑喇。
