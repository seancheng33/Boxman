我用一个 60MB 的压缩包，装好了人生第一个游戏引擎

大家好，我是「山岚的运维笔记」。

新系列今天开张啦。先立个 flag：接下来一段日子，我要带着完全零基础的你，从一个空文件夹开始，整一个正儿八经的推箱子游戏出来——能选关、能存档，最后还能打包成 Windows 程序和网页游戏那种。

唔使会编程，唔使懂美术，甚至不需要知道"游戏引擎"四个字是什么意思。一篇只讲一个知识点，讲到明为止，你跟着做就行。

今天第一篇，先把最容易劝退的一关过了：装环境。

**为啥是 Godot**

做游戏的引擎不少，我给新手首推 Godot，理由说出来有点土：它真的免费，而且小到离谱。

免费到什么程度？有的引擎的经典操作是"入门白送、你游戏赚钱了我抽成"。Godot 是开源社区维护的，你拿它做的游戏卖到断货，人家一分钱都唔收。

小到什么程度？官网下载一个 zip，解压出一个小 exe，没了。我出门经常把它扔 U 盘里，想给朋友 demo 一下就插上，颇有当年带绿色版软件出门的潇洒。

写代码用的是 GDScript，跟 Python 长得像两兄弟，后面系列里所有代码我都会一行行带着敲，你只管照抄，抄完就能跑。

版本提醒：咱们用 Godot 4.2.2。网上很多老教程是 3.x 的，接口对不上，跟着敲实报错，看到记得绕道，别跟自己过不去。

**安装，我尽量写得长一点**

为啥说尽量写得长？因为真的冇嘢可写。

官网 godotengine.org，点 Download，下载 Windows 标准版，得到一个 zip。解压到一个纯英文路径，比如 D:\Godot，双击里面的 exe。

没了。整个安装过程就这么短。

第一次打开是这个界面，叫项目管理器，你可以理解成"项目大厅"——以后你的游戏全部住在这里：

（图1：项目管理器首次启动）

它刚睁眼还会热情地问你要不要逛逛官方示例项目，点取消：

（图2：零项目提示弹窗）

咱们是来自己动手的，不逛别人家的后花园。

**切中文，三秒搞掂**

冷知识：Godot 会自动跟着系统语言走。你是简体中文的 Windows，一打开就是中文，这一节可以直接跳过。

看到英文界面的朋友，点项目管理器右上角的语言下拉，一长串语言列表哗啦全出来：

（图3：语言选择下拉）

一路滚到最底，[zh_CN] Chinese, China 在最底下等你，点它，界面即刻变中文。设置会自动记住，下次不用再弄。

**建第一个项目**

回到主界面，点左上角「+ 新建」，一屏选项看着挺唬人，其实就四个地方值得多看一眼：

（图4：新建项目对话框）

项目名称填 tutorial，跟我教程工程保持一致，以后每篇代码都好对照；路径选个纯英文的空文件夹；渲染器选最下面的「兼容」——2D 跑得最快，老显卡也带得动，以后导出网页版还得靠它，选贵的不如选对的；版本控制选「无」，现在开了只会提前生成一堆你看不懂的文件。

点「创建并编辑」，编辑器就开出来了：

（图5：编辑器首次打开）

恭喜，开发环境这块儿，你已经是就绪状态了。中间那片先不用管，下一篇我带你把整个编辑器里里外外逛一遍。

**最后**

盘点一下今天搞掂的活儿：解压一个包，确认中文，白嫖一个空项目。没写一行代码，但"装环境"这关拦住的人，可比后面的代码拦住的加起来都多，你今天已经跳过这个坑了。
