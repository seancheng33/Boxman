我用一个 60MB 的压缩包，装好了人生第一个游戏引擎

大家好，我是「山岚的运维笔记」。

新系列今天开张。先立个 flag：接下来一段时间，我要带着完全零基础的你，从一个空文件夹开始，做出一个正儿八经的推箱子游戏——能选关、能存档，最后还能打包成 Windows 程序和网页游戏的那种。

不需要会编程，不需要懂美术，甚至不需要知道"游戏引擎"是个啥。一篇只讲一个事，讲透，你跟着做就行。

今天第一篇，先把最容易劝退的一关过了：装环境。

**为啥是 Godot**

做游戏的引擎不少，我给新手首推 Godot，理由说出来有点土：它真的免费，而且小得离谱。

免费到什么程度？有的引擎的套路是入门白送、你游戏赚钱了我抽成。Godot 是开源社区维护的，你拿它做的游戏卖爆了，人家一分钱不要。

小到什么程度？官方下载一个 zip，解压出一个小 exe，没了。我出门经常把它揣 U 盘里，想给朋友演示就插上，颇有当年带着绿色版软件出门的潇洒。

写代码用的是 GDScript，跟 Python 长得像亲兄弟，后面系列里所有代码我都一行行带着敲，你只管抄。

版本提醒：咱们用的是 Godot 4.2.2。网上很多老教程是 3.x 的，接口对不上，跟敲必报错，看到记得绕道，别跟自己过不去。

**安装，我尽量写得长一点**

为啥说尽量写得长？因为实在没东西可写。

官网 godotengine.org，点 Download，下 Windows 标准版，得到一个 zip。解压到纯英文路径，比如 D:\Godot，双击里面的 exe。

没了。这就是全部。

第一次打开是这个界面，叫项目管理器，你可以理解成"项目大厅"，以后你的游戏都住这儿：

（图1：项目管理器首次启动）

它刚开还会热情地问要不要逛官方示例项目，点取消：

（图2：零项目提示弹窗）

咱是来自己动手的，不逛别人家后花园。

**切中文，三秒的事**

冷知识：Godot 会自动跟着系统语言走。你是简体中文 Windows，打开就是中文，这节可以直接翻篇。

看到英文界面的朋友，点项目管理器右上角的语言下拉，一长串列表会哗啦出来：

（图3：语言选择下拉）

滚到最底下，[zh_CN] Chinese, China 在等你，点它，当场变中文。设置自动记住，下不为例。

**建第一个项目**

回主界面，点左上角「+ 新建」，一屏选项看着挺唬人，其实就四处要看：

（图4：新建项目对话框）

名称填 tutorial，跟我教程保持一致，以后代码好对照；路径选个英文的空文件夹；渲染器选最下面的「兼容」——2D 跑得最快，老显卡也带得动，以后导出网页版还得靠它，选贵的不如选对的；版本控制选「无」，现在开了只会提前生成一堆你看不懂的文件。

点「创建并编辑」，编辑器就开出来了：

（图5：编辑器首次打开）

恭喜，开发环境这块儿，你已经是就绪状态了。中间那片先不用管，下一篇我带你把整个编辑器逛个遍。

**最后**

今天干成的活儿盘点：解压一个包，确认中文，白嫖一个空项目。没写一行代码，但"装环境"这关拦住的人，可比后面的代码拦住的多多了，你今天已经跳坑了。
