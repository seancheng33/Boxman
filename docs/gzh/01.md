我用一个 60MB 的压缩包，装好了人生第一个游戏引擎

大家好，我是老王（笔名按你实际署名替换）。

从这篇开始，我开一个新系列：**带着零基础的你，从空文件夹开始做一个完整的推箱子游戏**——能选关、能存档、最后还能打包成 Windows 程序和网页游戏那种。

不会有任何门槛。你不需要会编程，不需要懂美术，甚至不需要知道"游戏引擎"四个字是什么意思。每一篇我只讲一个知识点，讲透，你跟着做就行。

今天第一篇，先解决最劝退的一关：**装环境**。

**一、为什么选 Godot**

市面上游戏引擎一大把，我首推 Godot 给新手，理由特别朴素：

它**完全免费**，做游戏赚了钱也不用分成；它**小到离谱**，官方说法是一个 zip 包，实际上连安装器都没有——解压，双击，完事。对比动辄几十 GB、装半小时的大块头，这个开箱体验对新手太友好了。

它自带一门叫 GDScript 的语言，长得跟 Python 差不多，本系列后面所有代码都会一行行带着敲。

咱们系列用的是 **Godot 4.2.2**。提醒一句：网上很多老教程是 3.x 版本的，接口对不上，跟敲会报错，看到 3.x 教程记得绕道。

**二、安装：真的就是解压**

去官网 godotengine.org，点 Download，下载 Windows 标准版，得到一个几十 MB 的 zip。

然后：

解压到一个纯英文路径（比如 D:\Godot），双击里面的 exe。

没了。这就是全部安装过程。

第一次打开你会看到这个界面，叫项目管理器，相当于你的"项目大厅"：

（图1：项目管理器首次启动）

它还会弹出来问"要不要看看官方示例项目？"点取消就行：

（图2：零项目提示弹窗）

**三、切中文，三秒钟**

如果你的电脑是简体中文系统，Godot 启动时自动就是中文的，啥都不用动。

如果是英文界面：点项目管理器**右上角的语言下拉**，会展开一长串语言列表：

（图3：语言选择下拉）

一路滚到底，找到 **[zh_CN] Chinese, China**，点它，界面立刻变中文。设置会自动记住。

**四、建第一个项目**

回到主界面，点左上角「+ 新建」，四个地方要注意：

（图4：新建项目对话框）

项目名称填 tutorial，跟我后面教程保持一致；路径选个纯英文的空文件夹；**渲染器选「兼容」**——它跑 2D 最快，老显卡也扛得住，以后导出网页版也靠它；版本控制选「无」。

点「创建并编辑」，编辑器就打开了：

（图5：编辑器首次打开）

看到这个界面，恭喜，你的游戏开发环境已经完全就绪。中间那片先不用研究，下一篇我带你把编辑器的每个面板挨个认一遍。

**最后**

今天就到这，回顾一下：解压一个包、确认中文、建好项目，5 分钟搞定。
