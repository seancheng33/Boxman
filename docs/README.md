# Godot 入门实战教程系列

从零做一个完整的推箱子游戏（Windows + 网页双平台发布），面向零基础读者。

- **作者**：山岚的运维笔记（CSDN / 公众号同名）

- **引擎**：Godot 4.2.2（教学工程在 `tutorial/` 目录）
- **每篇一个知识点**，第一人称实战记录，配套真实运行截图
- **双平台版本**：`docs/csdn/`（CSDN 优化版）/ `docs/gzh/`（公众号版）
- **进度节点**：每篇完成时打 tag（`v0.1`、`v0.2`……），读者可下载对应进度的完整可运行工程
